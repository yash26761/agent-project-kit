# Support

## Questions and usage help

For questions about using this kit, open a GitHub issue and include the part of the kit you are using and what you expected to happen. Do not include secrets, private repository contents, or personal data.

## Bugs and suggestions

Use the bug report or feature request issue form. Before opening an issue, check whether a similar one already exists.

## Security issues

Do not report security issues publicly. Follow the private reporting guidance in [SECURITY.md](SECURITY.md).

This is a community project. There is no guaranteed response time or support service level.
