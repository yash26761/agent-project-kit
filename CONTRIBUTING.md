# Contributing

Thanks for helping improve Agent Project Kit. Keep contributions focused, broadly useful, and easy to review.

## Before you start

- Check existing issues and pull requests to avoid duplicate work.
- For a significant change, open an issue or discuss the proposal first.
- Prefer improvements that work across languages, tools, and project sizes.
- Avoid adding dependencies, setup steps, or rules unless they solve a clear problem.
- Do not include secrets, credentials, or unrelated personal data.

## Make a change

1. Create a branch for your work.
2. Make a focused change that follows the repository's `AGENTS.md` and existing conventions.
3. Run relevant checks documented by the project. If no checks apply, say so in the pull request.
4. Review your diff and remove unrelated changes.
5. Open a pull request using the provided template. Explain the reason for the change and any user-visible impact.

## Reporting problems

Use the issue templates when available. Include enough detail to understand the problem, but remove private information such as tokens, personal data, or internal URLs.

## Respectful collaboration

Be respectful and constructive. Focus feedback on the work and help make participation welcoming for everyone. Report security issues privately as described in [SECURITY.md](SECURITY.md).
